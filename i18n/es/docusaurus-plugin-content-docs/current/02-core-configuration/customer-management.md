La pestaña Gestión de clientes es donde configuras las reglas de comunicación automática para los usuarios que se registran o hacen reservas en tu sistema. Accede a ella desde **MHM Rentiva > Ajustes > Gestión de clientes**.

---

## 📧 Ajustes de comunicación con el cliente

Gestiona aquí las notificaciones por correo electrónico para mejorar la experiencia del usuario y mantener a tus clientes informados durante todo el proceso.

- **Enviar correo de bienvenida:** envía un mensaje de «Bienvenida» personalizado con tu marca a los nuevos usuarios que se registran mediante los formularios de MHM Rentiva.
- **Enviar notificaciones de reserva:** envía al cliente una actualización inmediata cada vez que cambia el estado de una reserva (p. ej., Pendiente → Confirmada o Cancelada).

### Resumen de la sección
- Usa la **comunicación posterior al registro** para establecer el primer contacto con los nuevos clientes.
