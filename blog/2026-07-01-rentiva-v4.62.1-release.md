A patch release fixing the Lite VIP transfer route limit counter, which silently failed to enforce the route cap on installs using the current routes table.

<!--truncate-->

:::warning Historical release note — this behaviour no longer exists

The Lite transfer-route cap this patch fixed was removed in **v5.0.0** along with the
rest of the Lite plan limits. Rentiva's free core places no cap on transfer routes, so
there is no counter and no limit notice. This post is kept as a record of what v4.62.1
shipped.

:::

## Fixes

- **Fix: the Lite VIP transfer route limit now counts routes correctly.** On installs using the current routes table, the limit notice showed "0 used" and new routes could still be created past the Lite limit because the counter read the wrong (legacy) database table.
